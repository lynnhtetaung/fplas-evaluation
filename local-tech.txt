==========================
Flutter install in linux
==========================

Download flutter sdk from Git.
git clone -b master https://github.com/flutter/flutter.git

mv flutter ~/flutter
echo 'export PATH="$PATH:$HOME/flutter/bin"' >> ~/.zshrc
source ~/.zshrc
close terminal ...
sudo apt-get update
sudo apt-get install curl git unzip xz-utils
sudo apt-get install libglu1-mesa
flutter doctor

flutter create my_application
cd my_application
flutter run

=====================================================================
Roboflow splits the dataset into Train, Validate and Test categories
=====================================================================
1. To Train the Model (Train Set)
Purpose: The training set is used to teach the model to recognize patterns in the data.
Content: This set contains the majority of the dataset (commonly 70-80%).
Role in Training:
The model adjusts its internal parameters (e.g., weights) based on this data.
It is exposed to these images and their labels repeatedly during training.
---------------------------------------------------------------------------------------
2. To Tune Hyperparameters (Validation Set)
Purpose: The validation set is used to evaluate the model's performance during training and fine-tune hyperparameters.
Content: Typically 10-15% of the dataset.
Role in Training:
Helps to check if the model is generalizing well to unseen data during training.
Used to decide when to stop training (e.g., early stopping) or adjust hyperparameters (e.g., learning rate, batch size).
Prevents overfitting to the training data.
----------------------------------------------------------------------------------------
3. To Evaluate Performance (Test Set)
Purpose: The test set evaluates the final performance of the model after training is complete.
Content: Usually 10-15% of the dataset, and it is kept completely separate during training.
Role in Training:
Provides an unbiased assessment of the model's performance on completely unseen data.
Used to calculate metrics like precision, recall, F1-score, or mAP (mean Average Precision).
